# Security Engineering

- `threat-models` — trust boundaries and abuse cases for identity, connectors, agents, and execution.
- `policies` — secure engineering, access, secrets, encryption, retention, and incident policies.
- `penetration-tests` — scope, reports, remediation, and retest evidence.

Sensitive platform mutations must use least privilege, short-lived credentials where supported, immutable audit evidence, tenant-defined limits, and emergency revocation.
