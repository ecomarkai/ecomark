# Compliance Evidence

- `pdpl` — Saudi privacy data inventory, purposes, roles, retention, transfers, and rights handling.
- `soc2` — control mapping and operating evidence.
- `iso27001` — ISMS scope, risk register, policies, and audit evidence.
- `vendor-risk` — AI, cloud, data, payment, communication, and connector supplier assessments.

Compliance evidence should be generated from real controls and operations, not documentation alone.
