# Product System

- `discovery` — interview evidence, problem statements, and design-partner learning.
- `roadmap` — outcome-based bets, dependencies, and decision history.
- `metrics` — north-star, activation, retention, profitability, and automation trust metrics.
- `pricing` — packaging, willingness-to-pay research, experiments, and unit economics.

Recommended strategic metrics include active connected stores, paying stores, managed GMV, managed ad spend, time to first verified value, accepted recommendations, verified actions, incremental contribution profit, gross retention, net revenue retention, and AI cost per store.
