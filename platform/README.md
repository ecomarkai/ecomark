# Internal Developer Platform

Provide repeatable engineering paths rather than asking each team to invent deployment, security, telemetry, and service conventions.

- `golden-paths/service-template` — standard service layout with health checks, telemetry, auth, tests, and deployment metadata.
- `golden-paths/connector-template` — standard OAuth, webhook, rate-limit, sync, replay, and reconciliation structure.
- `local-development` — reproducible local stack and sanitized seed data.
- `release-engineering` — build, provenance, promotion, rollback, and release policy.
