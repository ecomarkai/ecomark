# Technical Due-Diligence Index

Maintain evidence for:

- Source-code and intellectual-property ownership
- Dependency licenses and software bill of materials
- Architecture diagrams and decision records
- Security program, threat models, audits, and penetration tests
- Data rights, consent, lineage, retention, residency, and deletion
- Production SLOs, incidents, postmortems, and remediation
- Backup, restore, failover, and disaster-recovery exercises
- AI evaluation methodology, model inventory, and cost controls
- Customer usage, retention, outcome attribution, and platform reliability
- API dependencies, partner agreements, and connector risks
