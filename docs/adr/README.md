# Architecture Decision Records

Use one immutable record per material decision. Include context, decision, alternatives, consequences, owner, date, and review trigger.

Suggested first records:

1. Modular monolith before service extraction
2. PostgreSQL as the operational source of truth
3. Immutable raw event retention
4. Versioned canonical events and commands
5. Graph as a rebuildable projection
6. Multi-provider model gateway
7. LLM separation from financial calculations and execution
8. Durable approval and execution workflows
