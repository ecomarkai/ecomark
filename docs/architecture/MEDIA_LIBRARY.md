# Tenant media library

Each company has isolated folders, assets, versions, tags, usage rights and storage connections.
Original files remain in the selected provider. Ecomark stores canonical metadata, checksums and
searchable representations.

AI uses media.assets.search and media.assets.read_metadata. It receives approved asset IDs and
previews, never storage credentials or unrestricted bucket access. Selection considers product,
campaign, audience, language, rights and historical performance.
