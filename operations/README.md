# Operations

- `slo` — service-level indicators, objectives, error budgets, and alert rules.
- `capacity` — demand model, peak scenarios, load-test results, and scaling thresholds.
- `finops` — cost allocation by tenant, connector, model, and workflow.
- `incidents` — incident templates, postmortems, follow-up owners, and trend reviews.

Key product SLOs should cover API availability, webhook acknowledgement, data freshness, reconciliation accuracy, execution verification, and tenant isolation.
