# `@ecomarkai/ui`

Canonical shared design tokens and accessible UI primitives for Ecomark. Components use native elements, forward native props and refs, contain no authored user-facing defaults, and support inherited `lang`, `dir`, and `data-theme` values.

Import the global foundation once at the application boundary:

```css
@import "@ecomarkai/ui/styles.css";
```

Import components from `@ecomarkai/ui`. Applications own translation keys, locale routing, accessible labels, validation messages, and product content. See the repository [design system](../../docs/design/DESIGN_SYSTEM.md), [component standards](../../docs/design/COMPONENT_STANDARDS.md), and [accessibility requirements](../../docs/design/ACCESSIBILITY.md).
